# درع (Shield)

تطبيق ويب عربي يساعد من يتعرض للابتزاز بالصور على حماية صوره وحفظ الأدلة ومعرفة الخطوات الصحيحة.

## المميزات

- توجيه لخدمات الحماية الرسمية: [StopNCII](https://stopncii.org) للبالغين و[Take It Down](https://takeitdown.ncmec.org) لمن هم دون 18 سنة
- حفظ لقطات الأدلة داخل المتصفح على جهاز المستخدم فقط، دون إرسالها لأي خادم
- دليل بخطوات واضحة لمن يتعرض للتهديد
- وضع نهاري وليلي
- واجهة بالعربية والإنجليزية
- ملف واحد بدون أي مكتبات خارجية

## التشغيل

افتح الملف `index.html` في أي متصفح.

## النشر على GitHub Pages

1. ارفع الملفات إلى المستودع.
2. من Settings ثم Pages.
3. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
4. احفظ، وبعد دقيقة يظهر الرابط.

## ملاحظة

التطبيق لا يحجب الصور بنفسه. هو يوجّه المستخدم للخدمات الرسمية التي تتعاون مع المنصات.
